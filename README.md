# 🚀 Build a Junior Astronaut – Mission Trainer

## About the Project

**Build a Junior Astronaut – Mission Trainer** is an educational survival and resource management simulator set on Mars. The player takes on the role of a space mission commander, responsible for managing resources, building facilities, and making strategic decisions to keep an astronaut alive throughout a 30-day mission.

The main objective is to successfully complete the mission while maintaining the astronaut's health and the habitat's integrity.

## 🎯 Project Objectives

Develop an interactive game that simulates some of the challenges of a space mission on Mars, exploring concepts such as:

- Resource management;
- Planning and strategy;
- Decision-making;
- Programming logic;
- Sustainability and survival in extreme environments.

## 🎮 How to Play

The player must manage a Mars base and ensure the astronaut survives for 30 days.

Each day, the player has **2 available actions**, which can be used to build facilities or perform repairs.

Throughout the mission, the player must monitor available resources, astronaut health, habitat integrity, and random events that may threaten survival.

### Available Resources

- ⚡ **Energy:** Powers the base's systems.
- 💧 **Water:** Essential for the astronaut's survival.
- 🫁 **Oxygen:** Necessary for breathing.
- 🍎 **Food:** Provides nourishment for the astronaut.
- 🧱 **Materials:** Used to build and maintain facilities.

### Available Facilities

Players can construct different facilities to improve the base's conditions:

| Facility | Function |
|---|---|
| Additional Solar Panels | Increase energy production. |
| Hydroponic Greenhouse | Increase food production. |
| Water Recycler | Increase water production. |
| Oxygen Generator | Increase oxygen production. |
| Reinforced Shelter | Improves protection against external threats. |
| Maintenance Workshop | Allows repairs to the habitat and damaged facilities. |

## 🌪 Random Events System

During the mission, random events may occur and affect the base's conditions.

Some examples include:

- Dust storms;
- Water recycling failures;
- Greenhouse malfunctions;
- Low sunlight levels;
- Water leaks;
- Preventive maintenance;
- Severe storms;
- Structural failures.

These events can change resource production and consumption, as well as damage the habitat and facilities.

The base's protection system reduces damage caused by external threats.

## ❤️ Survival System

Survival depends on proper resource management and maintaining the base's conditions.

- The astronaut's health decreases when water, oxygen, or food levels become critical.
- The habitat can be damaged during events.
- Damaged facilities may lose efficiency.
- The maintenance workshop allows repairs using materials and available actions.

### Victory and Defeat Conditions

**Victory:** Survive until the end of the 30-day mission.

**Defeat:** Occurs when the astronaut's health or the habitat's integrity reaches zero.

## 🛠 Technologies Used

- **HTML5:** Page structure and game elements.
- **CSS3:** Styling, visual organization, and responsive design.
- **JavaScript:** Simulation logic, resource management, random events, construction, and survival conditions.

## ▶️ How to Run

1. Download or clone this repository.
2. Extract the files if you downloaded the project as a ZIP archive.
3. Open the project folder in Visual Studio Code.
4. Run the `index.html` file in a web browser.
5. Start the mission and begin managing your Mars base.

You can also use the **Live Server** extension in Visual Studio Code to run the project locally.

## 📚 Educational Purpose

In addition to providing an interactive experience, this project aims to demonstrate how planning, resource management, and decision-making are essential for survival in extreme environments.

The simulation also introduces concepts related to space exploration and the challenges of establishing a human settlement on Mars.
